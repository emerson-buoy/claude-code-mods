# claude-code-mods

Mods for Claude Code. Each mod is a plugin of function hooks that hot-reloads in a session.

## Mods

| Mod | What it does |
| --- | --- |
| `model-badge` | Shows the active model above the prompt. Updates on model switch. |

## Install

In a Claude Code terminal session:

```
/plugin install model-badge --marketplace emerson-buoy/claude-code-mods
```

Answer `y` to add the marketplace, then pick a scope.

## Develop

```
claude --plugin-dir /path/to/claude-code-mods
claude plugin validate .
```

Layout:

- `.claude-plugin/plugin.json` - manifest
- `.claude-plugin/marketplace.json` - makes this repo installable
- `hooks/hooks.json` - lists the hook modules
- `hooks/register.tsx` - the hooks
- `types/index.d.ts` - `$.state` contract

`.claude-plugin/types/` is generated by the engine on load and is git-ignored.
